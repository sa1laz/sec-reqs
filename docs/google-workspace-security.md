# Безопасная настройка Google Workspace: меры, риски, реализация

Источник рисков: 108 уникальных вопросов-ответов про Google Workspace из датасета `Vyber07/cyber-security` (файлы `220426-CyberSec-Dataset_escaped.jsonl` и `CyberSec-Dataset_escaped.jsonl`). Почти все они про обнаружение атак, а не про харденинг.

Ограничения:

- Официальной документации Google и бенчмарка CIS для Workspace в датасете нет.
- Столбец «Реализация» в основном дописан из знаний модели и **по документации Google не сверен**. Пути в консоли администратора указаны по памяти; Google периодически переставляет разделы.
- Ответы в датасете выглядят сгенерированными и местами путают продукты (например, Vault назван средством DLP, а для мониторинга Workspace предлагается Security Command Center из Google Cloud). Такие утверждения в таблицу не переносились.

Звёздочкой (*) отмечены меры, которых в датасете нет совсем.

## Таблица мер

## С чего начать

Если ресурсы ограничены, первые четыре меры:

1. Ключи безопасности для суперадминов.
2. Белый список OAuth-приложений.
3. Запрет автопересылки почты наружу.
4. DMARC в режиме `reject`.

Они закрывают самые частые сценарии захвата из датасета.
